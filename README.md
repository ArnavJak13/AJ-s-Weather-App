# 🌤️ Weather App

A simple Python weather application that fetches **real time weather data** for any city using the **OpenWeather API**.

![Python](https://img.shields.io/badge/Python-3.x-blue?logo=python)
![API](https://img.shields.io/badge/API-OpenWeather-orange)
![Status](https://img.shields.io/badge/Project-Completed-brightgreen)

---

## ✨ Features

- 🌍 Search weather by city name
- 🌡️ Choose between Celsius and Fahrenheit
- ☁️ View the current weather condition
- 💧 View humidity
- 💨 View wind speed
- 🌡️ View the "feels like" temperature
- 👁️ View visibility
- 🏳️ View country code
- 🔁 Search multiple cities
- 📜 View search history before exiting

---

## 🛠️ Technologies Used

- **Python**
- **Requests**
- **OpenWeather API**
- **JSON**

---

## ⚙️ How It Works

1. The user enters a city name.
2. The user selects **Celsius** or **Fahrenheit**.
3. The program sends a request to the OpenWeather API.
4. The API returns the current weather data.
5. The program extracts the required information.
6. The weather details are displayed in the terminal.
7. The user can search another city or exit.
8. On exit, the program displays the search history.

## 📦 Requirements

Make sure Python is installed on your system.

The project also requires the `requests` library.

Install it using:  "pip install requests".


🔑 API Setup
This project uses the OpenWeather API.
1. Create an account on OpenWeather.
2. Generate an API key.
3. Add the API key to the program.
4. Run the Python file.
⚠️ Do not upload your personal API key to a public GitHub repository.
